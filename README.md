# Point Ball

Jogo 2D multiplayer online (visto de cima), 5x5, com balas de borracha que ricocheteiam.

## Rodar no computador
```bash
npm install
npm start
```
Abra http://localhost:3000 — página de ajustes em http://localhost:3000/teste

## Subir no Render
1. Suba este repositório no GitHub.
2. No Render: **New → Web Service** → escolha o repositório (ou **New → Blueprint**, que usa o `render.yaml`).
3. Build: `npm install` · Start: `npm start`.

## Ajustar tamanhos e velocidades
Use a página `/teste`, clique em **Baixar config** e coloque o `game-config.json` na raiz do projeto.
